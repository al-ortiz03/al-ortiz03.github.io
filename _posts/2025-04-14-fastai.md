> The fastai website provides a series of interactive tutorials to help understand deep learning and AI. 

### FastAI Course
It is amazing to see how far machine learning has come in 10 years, as in the first lesson we were able to train a model to recognise birds from forests in a matter of minutes. 

### Challenges

Personally, it is challenging to use so much code from existing libraries, instead of writing my own code as I have done throughout most of my academic career. The challenge switches from solving problems and debugging code to reading documentation and deciding how best to use the available functions. I am having a similar experience in **CSSE4011** using ``Zephyr``, which is very documentation heavy. It is difficult as sometimes it feels as though I've spent hours working and not written much code - I've had entire assignments which were under 100 lines despite taking weeks. However, I can recognise this is an important skill to have, as leveraging existing libraries will make life so much easier in the long run.
